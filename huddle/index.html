Your league ID, team ID, and (if private) ESPN cookies are saved only in this browser's local storage, and sent only to the Worker URL you configure — never to any other server. The optional AI features on My Team and Trade send only computed summaries (roster/matchup/waiver data, or a proposed trade's rosters) to Anthropic (or, for the optional second opinions, xAI or Perplexity) using your own API key, never ESPN cookies or the raw ESPN response, and only when you turn it on. The final comparison sends the other AI views' written results to Anthropic too. See ARCHITECTURE.md for the one-time proxy setup this needs.
