Upload your wearable data

Export a CSV or JSON file from Oura, Whoop, Garmin, Fitbit, or any tracker's data export, and drop it in. Everything is parsed and analyzed in this browser — nothing is uploaded anywhere unless you turn on optional AI assistance below.

    File parsing and every baseline/pattern calculation happen locally in this browser. Nothing is sent anywhere unless you enable optional AI assistance, which sends only the computed summary (not your raw file) to Anthropic using your own API key.
